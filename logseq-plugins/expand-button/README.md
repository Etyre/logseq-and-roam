# Expand button (Logseq plugin)

Renders `{{renderer :rbutton, [[Label]]}}` (the converter's form of Roam's `{{[[Label]]}}`
buttons) as a small button. Clicking it expands the block the button sits in by one
level: children shown, grandchildren collapsed. `/button` inserts a new one.

Install: Settings → Advanced → Developer mode; Plugins → "Load unpacked plugin" → this folder.
