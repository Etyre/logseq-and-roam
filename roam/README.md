# Roam add-ons

Paste-in `{{[[roam/js]]}}` blocks (and, where needed, `{{roam/render}}` components) that
mirror the plugins in `../logseq-plugins/`. Eli installs and tests these; nothing here
is applied to the graph automatically.

## Installing a roam/js block

1. On any page (for example `roam/js`), make a block containing exactly `{{[[roam/js]]}}`.
2. Nest one child block under it, type ```` ```javascript ```` to open a code block, and
   paste the file's contents inside.
3. Click "Yes I know what I'm doing" on the warning that appears, then reload the graph.

| File | Feature | Logseq counterpart |
|---|---|---|
| `backwards-embed.js` | **Backwards embed**: type `/bembed` (or `/backwards embed`) in a block, use command palette "Backwards embed" (default hotkey Ctrl+Alt+E), or right-click a bullet → "Backwards embed". The slash trigger is removed from the block and fires as soon as it is typed (Roam has no API for adding entries to its own "/" menu); triggers are configurable via `slashTriggers`. Pick a page from the filtered list (or type a new name to create it); a new block is created on that page and `{{[[embed]]: ((uid))}}` is inserted at the cursor. With `parentBlockNames` set (default `Global notes:`, `General notes:`, `Notes:`, tried in order) the new block is nested under the first block on the page matching one of those names (also matches `[[…]]`, `#…`, and a trailing colon); if none exists it is appended at the top level (or the first name is created, with `createParentIfMissing`). Option `embedParentWithChildren`: embed the parent block itself (whole subtree in one embed), creating a child only when it has none. Settings are the `CONFIG` object at the top of the file. | `logseq-plugins/backwards-embed/` |
| `claude-in-roam.js` | **Claude in Roam**: type `/claude` in a block, or reference `[[claude in roam]]` or `[[cl:]]` in it, and the block becomes `[[claude in roam]]: <what you wrote>` with a `=>` child that fills with Claude's reply as it streams in, one block per bullet (nested bullets nest). To continue, add a sibling of `=>` with your next message and press Enter; the reply appears as its children. Claude's blocks are tinted. Your messages are bold; Claude's blocks are regular weight (the model may bold a key term). Finished turns (Claude's replies, answered follow-ups, the `=>` marker) are read-only but the cursor moves through them, Enter in one starts a new follow-up, and the cursor lands at the end of each reply ("Claude in Roam: toggle reply lock" to change the lock). Besides the conversation, Claude sees the chain of parent blocks above it (`contextMode: "parents"`; `"parents+siblings"` adds the other blocks under the closest parent, `"page"` the whole page). Model `claude-opus-5`, effort `low`, web search on (all in `CONFIG`). Setup: paste as a roam/js block, reload, then command palette → "Claude in Roam: set API key" (reuses the Auto-anki key if set). Also: command palette / right-click → "Claude in Roam: ask here". Built from `claude-chat/core.js` + `claude-chat/roam-adapter.js` by `claude-chat/build.sh`. | `logseq-plugins/claude-in-logseq/` |
| `auto-anki.js` | **Auto-anki**: tag a block with `#[[auto-generate cards]]` or `[[LLM-generated cards]]` (configurable). Its siblings and their subtrees are read by Claude; its children become Anki notes in ankify format (`{c1:…}` cloze, or question + child answers, `#ankify` on each). With more than 6 notes they are filed under labelled heading blocks, 2 to 6 notes per heading, at most two heading levels (`CONFIG.grouping`). The section gets a purple border with a small ↻ button and a dot that turns amber when the source content changed since the last run. Notes you edit turn amber and are never touched by the LLM again; notes you add yourself count as edited. Bookkeeping lives in a hidden `#auto-anki-state` child block. Your edits, own notes and deletions are collected on the page `auto-anki/examples` and sent with every request so the model learns your taste; the instructions live on `auto-anki/prompt` ("Auto-anki: edit prompt" creates it). Setup: paste as a roam/js block, reload, then command palette → "Auto-anki: set API key" (stored in the browser only). Update via the ↻ button, the command palette or right-click → "Auto-anki: update cards". A home block inside a template definition (under `#roam/templates` / `#SmartBlock`) or tagged `#[[auto-anki off]]` is inactive (dashed border). Settings (`CONFIG`): home tags, off tags, template tags, ankify tag, model/effort, extra instructions, auto-update after N quiet minutes, show the state block, hotkey. Built from `auto-anki/core.js` + `auto-anki/roam-adapter.js` by `auto-anki/build.sh`. | `logseq-plugins/auto-anki/` |
